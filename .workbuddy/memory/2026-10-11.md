### 经验/坑（有长期价值的记法）
- **第六条扫描线：训练—部署一致性审计** —— 不问「缺什么动词」（10-08）、「什么不免费」（10-09）、「活多久」（10-09E），而问「**我们优化的那个对象，和被部署的那个对象，是同一个吗？**」。命中结果：训练框架里的 agent 是**重写版**（砍掉超时兜底 / 脏数据清洗 / 压缩长度 / system prompt 拼接顺序），于是「训得好、上线崩」被错记在「模型泛化不行」账上。六条扫描线现为：**时间 / 抽象层级 / 动词 / 资源定价 / 生命周期·作用域 / 训练—部署一致性**。
- **09-24 那条横断主题又开出新一格**：「**模型不是唯一可以放控制的地方**」说的是推理侧；本条把它推到训练侧 —— **既然控制不在模型里，训练就不能只喂模型**。同一条纪律换作用对象，是开格成本最低的方式。
- **可靠性与质量是两个正交轴，此前一直混记**：「一次运行可以可靠地跑完却给出糟糕答案，也可以给出一次精彩答案却活不过下一次部署——两者都要测。」⇒ **持久化执行（跑得完）与 evals（跑得好）必须分栏**，不能互为替代指标。
