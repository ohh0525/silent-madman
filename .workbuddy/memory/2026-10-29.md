- **记忆税 / Memory Tax** ⭐⭐（`arXiv:2610.34073`，UIUC 11 作者）—— 把朴素 RAG 当基线，记忆的净值 = benefit − tax；11 个记忆系统在 LongMemEval-s 上**全部输给 two-round RAG**（81.4 vs 最近 A-Mem 79.4），A-Mem 建库 **117 小时** vs RAG **0.11 小时**。⇒ 本库**没有 RAG 页**（`RAG` 全库仅 5 次、无 `concepts/RAG.md`），而 overview 最老开放项与台账最老 `⏸`（09-17 RAG，**41 天**）**两条独立计数指向同一件事** —— 本行是第一台能同时结清两者的仪器。⚠️ **与 10-22B 的 `MemoryTax`（`2610.29823`，单作者 / n=1）同名不同文**，已在报告内显式分栏。
- **常驻上下文的衰变 / OSTEON** ⭐⭐（`arXiv:2610.31306`）—— 452 个高 star 仓库中 **48.67%** 有 agent 上下文文件，其中**命名了仓库路径的中位文件里 9.5%–22% 的路径解析不了**。⇒ 🎯 10-09 那行落地的是「**留不留**」，本行补另一半「**留着的这份已经不真了**」；与 Breunig 的 strategic forgetting（记忆/skill **累积冲突**）是**同一格的两个方向**（陈旧 vs 矛盾）。⚠️ 作者自陈 **no measured effect**，是论点论文不是效果论文。
- **判官偏向「更多记忆」** ⭐（`arXiv:2610.31272`）—— 87 人 / ~1,000 组真人成对判断：**自动判官远比用户更频繁地选择带记忆的回答**。⇒ [[AgentObservability]] 五层都在问「测得准不准」，**没有一层问「评分函数自己有没有偏向」**。
