### 候选 1 ⭐（**新行**；补上 Cluster E 缺的动词「**看**」，且命中 10-07 新立的最高优先级判据）

**概念名**：智能体可观测性与评测 / Agent Observability & Evaluation

**为什么「当下」最有价值（一句话点明缺口）**：Cluster E 三页回答了「**谁跑循环**」（[[AgentHarness]]）、「**在哪跑**」（[[AgentSandbox]]）、「**跟谁合作**」（[[MultiAgent]]），却**没有一页回答「怎么看见它跑了什么、跑得对不对」**——而这个动词是**另外两页的验收前提**：[[HumanInTheLoop]] 的验收标准明写要测 automation / override / **escape** rate，[[AgentSandbox]] 的动机证据是 HF 入侵解剖（**都得先「看得见」**）⇒ 命中 10-07 刚立的优先级判据「**某页的验收标准落在另一页身上、而那一页不存在 ⇒ 最高优先级**」。

**一句话定义 + 边界辨析**：**用结构化遥测（trace / span / metric）重建 agent 一次运行的「做了什么、花了多少、谁回答的、对不对」的实践**——判据句 **「Trace 答『发生了什么』，eval 答『做得好不好』」**。边界：vs [[AgentHarness]]＝**机制 vs 见证**；vs [[Provenance]] / [[CitationLock]]＝**答案的溯源 vs 执行的溯源**（同一条「来源可信」纪律的新对象）；vs [[HumanInTheLoop]]＝闸门**需要** escape rate，本条**提供**它；vs 09-17「Agent Evals」＝**看 / observe** 与 **判 / evaluate** 是两个动词（**建议同页两章，合并成一篇**）；vs 09-25「评测经济学」＝成本侧。

**概念名**：智能体支付与商务层 / Agentic Payments & Commerce（AP2 / ACP / x402 / MPP）

**为什么「当下」最有价值（一句话点明缺口）**：wiki 的行动侧固定顺序 `propose ─▶ resolve ─▶ authorize ─▶ gate ─▶ **execute**` **止于 execute**——它从不涉及**花钱**；而支付是「不可逆动作」的**第一个真实预算面**，也是 agent 从**建议**跨到**成交**的那条线（[[HumanInTheLoop]] 的「**read freely, keep writes human**」缺一条对应物：**cap the spend**）。
