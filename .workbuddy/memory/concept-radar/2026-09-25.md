### 候选 1 ⭐ 首选:Agent 沙箱 / 执行隔离(Agent Sandbox / Execution Isolation)

**一句话点明缺口**:你的 [[overview.md]] 里 **Cluster D 的三条页全部明确声明自己「不是沙箱」**,Open Questions 里写着「execution isolation as the missing third leg」——而**本周这个缺口被填了两次**:Docker 2026-09-24 发布 Cloud Sandboxes,Nvidia 2026-09-21 发布 OpenShell。一条雷达候选在一周内被两家头部厂商各自产品化,此前从未发生过。

### 候选 2:记忆时效性基准 / 「旧记忆比没记忆更糟」(Memory Freshness / Stale-Memory Evaluation)

**一句话点明缺口**:你的记忆簇(写入-溯源-引用-拒答四页)回答的全是「**怎么记得住、记得可信**」,**没有任何一页回答「记得的东西还有效吗」**;而 2026-09-20 开赛的 **Agent Memory Challenge Cycle 2** 把这条缺口直接做成了公开基准——主办方原话:「**In some cases, stale memory may be worse than no memory at all.**」

### 候选 3:Agent 评测经济学 / 评测税(Agent Evaluation Economics / The Evaluation Tax)

**一句话点明缺口**:你的库里有 [[LongMemEval]] 这个具体基准,但**没有一页回答「跑评测本身要花多少钱、谁来付」**;而 2026-09 上旬五家实验室十天连发五个前沿模型(输入价差 **67 倍**),把「每接一个新模型 = 一轮基准测试 + 路由改造 + 合规审查」的**评测税**推成了结构性的经济问题——agent 团队**评测预算可以和推理预算同量级**。
