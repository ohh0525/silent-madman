### 11-25A 事实带着上下文存 / ContextFact（检索单元边界） ⭐⭐⭐

**一句话**：先证明「事实裸存 + 检索时补上下文」补不回所有洞——**读整个记忆库能暴露一批检索选择根本解决不了的缺口**，相邻轮分组在相同唯一轮预算下改善证据可达性、更宽窗口反而不稳定——再据此把「保留语境的事实记忆」与「有出处的实体表征」链接起来：会话内收集解释每条事实所需的上下文，跨会话对齐同一指称并回原文重建实体表征；查询时事实视图与实体视图各自重排、实体链接扩展拉出相关事实，用完整实体表征提供跨会话证据。以 Qwen3.5-27B 为骨干达 SOTA，却只用最强基线 **21%** 的证据 token，LoCoMo **86.49%**、LongMemEval-S **91.00%** 总体裁判准确率。5 作者，v1 2026-11-22，cs.CL+AI。

- **概念名（中英）**：事实带着上下文存 / Context-Preserving Fact Memory（ContextFact）
- **为什么"当下"最有价值**：[[LongTermMemory]] 的三记忆设计默认「事实可裸存、检索时再补语境」，A 第一次用「读全库暴露检索补不了的洞」给出反证——**部分上下文必须在 memory construction 时就留住，不是 retrieval selection 能救的**；这把台账最老的开放项之一「RAG / 检索准入」（🎯 10-13 相邻）从「检索侧」往「写入侧」推了一格。而且「21% 证据 token 达 SOTA」正面接 10-22B MemoryTax 的「MemoryTax 张力」——不是靠多喂证据，而是靠**存的时候存对单位**。

- **一句话定义 + 边界辨析**：定义——把「保留解释语境的事实记忆」与「回到原文重建的实体表征」双向链接，查询时双视图独立重排 + 实体链接扩展。边界：① vs 11-23B MemCredit（记忆价值从语义相关→决策效用）——那条改的是**选择哪条记忆**，本条改的是**记忆存进去时的单位与链接结构**，一个在召回侧、一个在构建侧；② vs [[Provenance]]（每条事实带来源/时间/证据）——那条给事实挂出处标签，本条更进一步把**原文语境本身存进事实单元**、并跨会话回原文重建实体，是 provenance 的物化形态；③ vs RAG 分块——RAG 按长度切块，本条按**「解释一条事实所需的局部语境」**划单元，边界判据不同。

### 11-25B 自演化 harness 的经验取舍 / Demystifying the Autoresearch Harness（context folding + skill deletion） ⭐⭐⭐

**一句话**：把自演化 autoresearch agent 的 harness 拆成两个正交维度做受控消融——**上下文管理**（从过去尝试里保留什么）与**技能管理**（怎么存和复用教训）。以 recency-truncation 为基线，在 MLE-Bench 与 KernelBench 上用 gpt-oss-120b / gpt-6-luna / gpt-6-sol 逐个隔离设计选择：上下文侧，**逐条可访问的过去尝试记录优于滚动摘要**，context folding 在全部六种设置里最好、最高比基线 +19.2%；技能侧，**选择性丢弃长期闲置的教训平均优于合并它们或升格为常驻规则**；把两者合起来做 MLEvolver，在 MLE-Bench Lite 拿 **72.7% 奖牌率**、KernelBench Level 3 拿 **94% fast1**，同推理预算下大幅超过 AIDE 与 OpenEvolve。11 作者，v1 2026-11-20，cs.AI，32 页/17 图/5 表。

### 11-25C 压缩边界上的授权 / Authorization Across Context Compaction（Progent） ⭐⭐⭐

**一句话**：像 Progent 这样「从用户请求推导 agent 能做什么」的 request-derived authorizer，其保证全押在**归因**上——请求被当成用户说的话；而压缩把它打碎了：观测到 Claude Code 与 Codex 每次自动压缩都把模型写的摘要**当成 user message 放回**，于是 compactor 对用户、文档、注入文本的引述统统读成「用户本人在说」。因为首个请求就把策略冻结会让 agent 做不完后续任务，作者让 Progent 对每个请求重新推导策略，结果发现**它授予什么完全跟着 compactor 写的东西走**。即便收款人由用户明说也不安全：当攻击者把另一账号写成纯数据的通知、用户要求付房租，从前沿 compactor 摘要推导的策略 **91%** 情形放行攻击者的账号，而从用户原话推导的策略 **零次**放行。原因是普遍的：作者证明**一个看不到「哪个字节是谁写的」的 authorizer，对伪造记录与其模仿的真迹的区分能力不可能超过两者本身的可区分度，且该上界紧致**。修复顺着归因走：authorizer 只采信用户说的话、到达时即认证并逐字跨边界携带，agent 仍读摘要；证明它要么收到那段原文、要么什么都没收到，攻击者能阻断策略但不能塑造它。40 个受攻击 AgentDojo episode 用修复重跑，agent 读摘要时无任何攻击者动作完成。5 作者，v1 2026-11-24，cs.CR+AI。

- **概念名（中英）**：压缩边界上的授权 / Authorization Across Context Compaction（Progent + attribution-bound）
- **为什么"当下"最有价值**：这是 10-22A「压缩即治理边界 / Compaction Laundering」从**案例到定理**的升级——那条只示范「摘要能把伪造轮次洗成真指令」，本条给出**不可能性定理**（看不到作者身份 ⇒ 区分力上界紧致），并证明「compactor 保留什么、怎么标注，本身就是安全参数」。正面接第 20 条授权口径审计（见 `SCAN-LINES.md`）的决策侧：攻击走的不是「指令改写」而是「把用户原话在压缩边界上替换成模型摘要」，与 11-24B 手写 authority rule 同效形成呼应——**朴素的「只认用户原话 + 逐字携带」就能顶掉复杂策略**。修复的「阻断可行、塑造不可行」还给 [[HumanInTheLoop]] 的 refuse 语义补了一条可证明的强形态。
- **来源链接（均 [verified]，一手 abs 已 WebFetch 直开核验）**：
  - https://arxiv.org/abs/2611.32194 [verified] —— 一手 abs（直开）：标题、5 作者（Zeming Fei / Hongming Fei / Yi Xu / Xiaoyang Wang / Ying Zhang）、v1 2026-11-24、cs.CR+AI、定理与全部数字出自此页摘要
  - https://arxiv.org/pdf/2611.32194 [verified] —— 一手 PDF（abs 页 View PDF 链接）
  - https://arxiv.org/html/2611.32194v1 [verified] —— 一手 HTML 全文（abs 页 HTML 链接）
- **一句话定义 + 边界辨析**：定义——证明压缩破坏授权归因，给出「伪造/真迹可区分度」的紧致上界，并以「用户原话到达即认证 + 逐字跨边界」修复，使攻击者只能阻断策略不能塑造。边界：① vs 10-22A Compaction Laundering——那条证「摘要能洗白伪造指令」，是本条现象的具体一例，本条给出**定理 + 授权层的一般化**；② vs 第 20 条授权口径审计——那条的攻击走「值篡改/来源无权」，本条走「压缩重写了来源身份本身」，是授权轴的**跨边界形态**；③ vs [[Provenance]] / [[CitationLock]]——那两条要求「只引打开过的、带出处」，本条指出**出处标签在压缩边界会被 compactor 重写**，因而必须在协议层逐字携带认证原文，是对 provenance 的**落地强制化**。

## 三、方法沉淀与结转

- **谱系/母题**：三条同落「**边界穿越后身份还成不成立**」——A 事实过「写入→取出」界（语境是否留存）、B 经验过「attempt→attempt」界（保留单位）、C 授权过「压缩」界（来源是否被顶替）。判别式轴 +3（**事实的存取单位 / 经验跨 attempt 的保留单位 / 授权凭据在边界两侧的载体**），时位补 3 格（**存取时 / 折叠时 / 压缩时**）。C 与 10-22A 成「案例→定理」对，B 与 11-24B 成「采纳时→留存时」对，A 与 11-23B 成「构建侧→召回侧」对。
- **备查（不入候选）**：CompAct-Bench（`2611.25673`，12 前沿模型压缩续跑、最强 Claude Opus 5 仅 68.5%，二手 digest 已见、一手 abs 未直开）——与 11-25B 的「滚动摘要失效」同侧，可作 B 的评测佐证；DriftGuard（用成对反事实重放找出导致记忆漂移的条目，同源 digest、一手未开）；AEGIS 零信任 HPC（`2611.32958`，v1 11-24，一手 abs 已见二手、未直开）——行为证明式运行时防御，与 11-12A Airlock 事后围堵同族，等第二形态；State-Transfer Auditing（`2611.23346`，hash-chain 审计状态迁移，仅二手）。
