### 候选 1 · 10-25A ⭐⭐

# 马赛克效应 / The Mosaic Effect

**一句话定义**：多条**各自都已获授权**的读取，可以被合成为一个**从未有人授权过**的结论 —— 而这个结论恰恰是唯一敏感的东西。

#### 为什么「当下」最有价值

> **本库行动侧整条链的每一格，判定对象都是「这一个」请求；而本被禁止的东西从来不在任何一格里面。**

展开看：本库的行动侧五段链 —— `propose → resolve([[ToolHallucination]]) → authorize([[AgentIdentity]]) → gate([[HumanInTheLoop]]) → execute` —— **每一段的判定对象都是单件**。其中 [[AgentIdentity]] 的 per-hop attenuation 写得最直白：**每一跳的权限只能收窄**。问题是：**逐件通过是这些机制的成功判据，而不是它们的边界条件。**

而同一篇论文里那句更狠的话直接咬在本库另一根承重柱上：

> *"increased refusals do not guarantee confidentiality, since significant refusals reveal the prohibited conclusion regardless"*

本库 [[Abstention]] 被写成阅读纪律的**安全终态**（无来源证据 ⇒ 拒答）。本行证明：**拒答本身会把那个禁止的结论带出来**。⇒ 拒答不是终态，它是一个输出通道。

#### 关键证据

- 规模：**30** 个合成样例（网络安全 / 医疗 / 军事）→ 三个 LLM agent 受控模拟 **10,800** 条终答 + 两个开源外壳中 live agent **1,440** 条。
- 即使是**设计成单个文档即可回答的良性查询**，被测最好的模型 **GPT-5.6-Sol** 仍泄漏禁止合成结论 **7.08%**（95% CI **3.75–10.67%**）；**live 外壳下更差**。
- 加上**可见密级页眉 + 显式聚合规则**后泄漏显著下降，但**跨全部意图**仍有 **32.37%**（95% CI **28.33–36.19%**）的不安全披露残留。⇒ **告诉 agent「不要聚合」本身不够**。

### 候选 2 · 10-25B ⭐⭐

# 删除的闭包 / Deletion Closure (AfterDeleteBench)

**一句话定义**：删除一条原始记录 ≠ 删除它派生的那些东西；当完整原文已经不存在、只剩分散存储的各分量且其**组合规则是公开的**时，秘密仍可被精确重建 —— **62–99%**。

#### 为什么「当下」最有价值

> **本库的溯源是单向的：[[Provenance]] 只向后（这条事实来自哪里），而删除闭包需要向前（这条来源派生出了什么）。**

本库 [[Provenance]] 的定义是「每条存储的事实携带**出处 / 时间 / 证据**」—— 一个**从后代指向祖先**的指针。删除闭包要求的是**反方向**：给定这条来源，**派生出过什么**。本库没有这一格，于是出现一个干净的失效：

[[MemoryGovernance]] 四动作里的 **DELETE**，可以在**记录层**被判定为「已正确执行」（那条记录确实没了），而秘密仍然**完全可重建**。⇒ **第四条底线 `auditable` 到目前为止只审了「有没有删」，没审「派生链有没有一起垮」。**

#### 关键证据

- 设计：对每个合成秘密，比较「**暴露后删除**」的 agent 与「**从未暴露**」的**配对对照** agent ⇒ 恢复可归因于原始暴露。
- 主设定：**单次查询**即从 Qwen2.5-7B-Instruct 找回被删秘密约 **三分之二**；从未暴露的对照 **零恢复**。
- **承重**：**不需要留下逐字副本** —— 完整秘密字符串已不存在、只剩分别存储的各分量且组合规则公开时，跨 Qwen / Mistral / Phi-3 的精确重建成功率 **62–99%**。
- 两种修法对照：
  - **provenance-aware closure**（连同派生记录一并删）→ 消除观测到的恢复；
  - **exact-literal write filter**（字面量写过滤）→ 挡得住重新插入，**但抹不掉系统里已有的信息**。
- 方法层一句：*the response interface is part of the measurement system*（格式 / 解析器错配会把含目标信息的回复判为失败）。

### 候选 3 · 10-25C ⭐（证据最薄，明确降权）

# 检测≠修好：给「重试」一个支付门槛 / Repair, Not Detection

**一句话定义**：能不能**发现**一个错误从来不是瓶颈 —— 一个旗标只有在 **检测器精确率 > D/(R+D)** 时才配得上它那次重试；而 R（重试真正修好的比率）往往低到**即便检测器完美也无济于事**。

#### 为什么「当下」最有价值

> **本库几乎全是检测器；10-19B「Finding ≠ Fixing」早就命名了这个缺口，但一直缺少一台定价仪器。本行交出的不是又一句口号，而是一个付款条件。**

它会同时咬住四页：

- [[MultiAgent]] 的「**验证器是前提**」—— 一个旗标不能被修的验证器，等于什么都没做；
- [[ToolHallucination]] 的封闭世界消解 —— 检出「工具不存在」之后做什么？
- [[MemoryGovernance]] 的四动作 —— 每个动作若不配后续修复，就只是检测器；
- [[CitationLock]] —— 锁住引用之后，被拒的那一段由谁来补？

而这次咬的位置比以往更靠前：过去的版本问「**这个修复动作存在吗**」（10-19B），本行问的是「**就算存在，它值不值这次调用**」—— 把「要不要重试」从直觉变成一门自变量的算式。

#### 关键证据

- 前提：无参考答案 / 无裁判模型 / 不更新权重；模型为**冻结的 LLaMA-2-7B-chat**，数据集 **GSM8K**。
- 三种免参考答案的替代品各以不同方式失效：**自评会把它要保护的那份答案一起变差**；采样一致性测的是**稳定性而非正确性**；扰动研究用人类模板偷读期望答案（**考的是模型不是轨迹**）。
- **AUROC 0.741 的天花板是结构性的**：**三分之二的错误轨迹没有写错任何一条等式** —— 它们把一个**错误的计划正确地执行完了**；且在「错计划」型失败上，检测器给错误轨迹打标的频率**低于**正确轨迹。
- 形变探针：1,319 题中 **937**（71.0%）存在有效扰动；847 条首轨迹可解析者，被支持者正确率 **60.6%**（基础率 **31.6%**），但探针也**否证了 45.5% 的正确轨迹**。
- **承重公式**：*"A flag earns its retry only when detector precision exceeds **D/(R+D)**"*；本研究 R 低到**即便完美检测器**在同预算下也只估计找回 **1,319 题中的 66 题**。

## 三、方法增量：第十九条扫描线
