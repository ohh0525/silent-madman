## 二、概念雷达(阶段二 · 3 条候选)

**本期母题**:记忆的读写动作各自补上一道判据,审计侧拿到第一份分维度诊断仪 —— A 给**读侧**(召回已饱和,瓶颈是消解:消歧哪个实体 / 哪个时间态 / 该不该答),B 给**写侧的上游变更后果**(矛盾记忆被改了、派生信念没被撤销),C 给**审计侧**(总体召回掩盖了「漏了哪类 + 良性误报」)。三条共同反对一个默认假设:**「取对了就对了 / 改对了就对了 / 抓到了就对了」**——每一个「对了」后面都藏着一个此前没被分开测的维度。判别式轴 +3(**记忆消解的对象 / 状态修订的级联单位 / 审计粒度的分化**),共 **35 轴**。时位补两格:**消解时**(读侧提交答案前的歧义裁决)、**审计时**(运行后的风险归因)。

**谱系观察**:上一期(11-15)把「越界」从攻击叙事切到系统叙事;本期把视角移到**记忆一致性**——11-13/11-14 的「记忆卫生三时点 + 生命周期两端」此前讲的是「何时对记忆做动作」,本期三条讲的是「做这个动作时要判对的那个维度根本没被单独测过」。A 与 B 恰成**读写对偶**:A 说写入时保留一切、读时才裁决(非对称),B 说上游一变、下游派生状态必须级联失效——两者合起来是「记忆的一致性维护」读写两面。

### 11-16A DISCERN 写时保留 / 读时消解 —— 召回已经解决,没解决的是判断 ⭐⭐⭐

**一句话**:企业 agent 跨数十个会话累积记忆、事实互相矛盾/被推翻/同名实体在嵌入空间里糊成一团;业界把它当检索问题,DISCERN 证明**不是**——留存与时效(retention/currency)已近饱和(0.93–0.98),真正的瓶颈是**消解**(resolution):这条查询指哪个实体、哪个时间态当前、以及到底该不该作答。

**为什么当下最有价值**:它正面顶到 overview 最老的开放项(RAG 案例研究)与 Cluster F 的承重结论(MemoryGovernance「瓶颈是四动作质量而非窗口容量」)——DISCERN 更进一步:**连四动作里「召回」那部分都已饱和**,剩下的全是判定。它给 `Abstention`(无溯源证据 ⇒ 拒答)第一次配上一道 100 道不可答题的量化(F1 0.924),并把「该不该答」细分成四种互斥终端动作(answer / update / clarify / abstain),而此前本库对拒答只有定性原则。

**数字(一手 abs 已核,2026-11-16 WebFetch arxiv abs 页)**

- ENT-310:合成企业销售 agent 记忆基准,310 条查询(210 可答 / 100 不可答);四个判官的 LLM-as-a-Judge council 分别评「可答题的答案正确性」与「答 vs 弃答」的分类表现。
- 留存与时效近饱和,约 **0.93–0.98**(每个像样的系统都如此)⇒ recall essentially solved;差距全在 resolution。
- 弃答校准最强:**F1 0.924**,八个 baseline 上限仅 0.802;宏观答案正确性 **0.861 vs 0.806**(最强 baseline),领先来自**实体消解 0.800**(无 baseline 超过 0.40)。
- 零调优迁移到完整 LoCoMo:宏观答案正确性仍领先 **0.663 vs 0.638**,误前提弃答仍在最佳校准之列 ⇒ 非基准特化。
- 机制:写入时构建**严格追加的双时序(bi-temporal)溯源图**,从不合并易混实体、从不丢弃被推翻的旧值;读取时以**零 LLM 工具面**驱动 agentic loop 导航该图,提交且只提交四种门控终端动作之一。

**边界辨析要点**

- **vs 11-13B WikiTrace(记忆的举证责任)**:那边是沿「洞见→成因摘要→原始轨迹」**下钻核实存疑经验**,属写侧/经验侧;DISCERN 是召回完成后的**读侧消解裁决**——处理的是「证据都在、但要判给谁、判不判」。一者举证,一者裁决。
- **vs `Abstention` / `CitationLock`**:Abstention 只给定性原则;DISCERN 把它做成四终端动作之一并配 100 道不可答题的 F1 0.924,且「该不该答」与「答得对不对」分成两条正交评分轴。
- **vs `Provenance`**:双时序溯源图是溯源**时间维度**(valid time + transaction time)的机械形式——本库此前只记「来源 + 时间 + 证据」,没有把「被推翻的旧值不删、只标记失效」写进结构。

### 11-16B StateGraph 依赖感知状态修订 —— 矛盾记忆改了,派生信念没撤 ⭐⭐⭐

**一句话**:长寿命 agent 的记忆必须跟着世界变;但上游事实一变,记忆系统只把被反驳的那条记忆本身改掉,而**从它派生的信念、计划、行动仍被当作有效**,尽管它们早已失去支撑。StateGraph 把这件事形式化为「依赖感知状态修订」,并造了第一台测它的仪器。

**为什么当下最有价值**:本库 10-29A「记忆错误会复利」只讲了**写错**的下游后果;StateGraph 补上它的反面——**错误删了、撤销没传播**:修正一处事实,依赖它的十条结论还站着。它给 11-13B WikiTrace 的「沿证据链向上举证」配了一个反方向的「沿依赖链向下撤销」(反事实:删掉前提看下游能否存活),并把 10-26「失效沿依赖图到达」从运行时执行图搬到**记忆信念图**。

**数字与机制(一手 abs 已核,2026-11-16 WebFetch arxiv abs 页)**

- StateGraph 维护一张演化的**状态依赖图**,边从交互历史中恢复;核心是**反事实验证**:对每条候选边问「去掉前提后,依赖状态还能否存活」,以此把**支撑依赖**与**语义相关**分开。修订只在「严格依赖失败且无独立支撑路径存活」时才令依赖状态失效。
- StateChangeBench:50 个作者构造的受控案例,标注级联深度、困难负例与行动后果。
- 对 CUPMem 复现版,Impact-F1 优势在**深度 1 为 6.9 个百分点、深度 3+ 为 26.0 个百分点** ⇒ 越深的级联,显式依赖跟踪收益越大。
- 公开长期记忆基准上,多数数据集的点估计与所评 baseline 相当或更高。

**边界辨析要点**

- **vs 10-29A「记忆错误会复利」**:那边是「写错的记忆会复发」(错误进入→持续伤害);这边是「修正后的失效没传播」(错误退出→残留伤害)。同一条复利链的两个方向,须互指。

### 11-16C ReA-Bench 负责任审计诊断基准 —— 总体召回掩盖了漏了哪类、误报了多少良性 ⭐⭐

**一句话**:审计 agent 的执行轨迹本是为发现风险,但生产与红队轨迹显示**某些风险跨审计配置反复被漏**;总体召回这个单一数字既看不出漏的是哪类风险,也看不出更高召回是不是拿「对良性行为的误报」换来的。ReA-Bench 把这件事做成第一台**分维度**的诊断基准。

**为什么当下最有价值**:本库扩展九 `AgentObservability` 讲的是「看得见 ≠ 读得懂」,ReA-Bench 再进一层——「抓到了 ≠ 抓对了」:它 first-class 地把「良性动作长得像风险、但与任务及授权一致」做成样本,并给配对轨迹(缩短 / 补齐缺失信息)测「审计者到底是被误导、接受了无支撑结论、还是压根缺信息」。它把 11-11B「监督者可被说动」之外的一类**无对手审计失效**(系统性盲区而非被攻陷)立成仪器。

**数字与主张(一手 abs 已核,2026-11-16 WebFetch arxiv abs 页)**

- 六层审计挑战:内部安全知识 / 轨迹内矛盾 / 长上下文证据检索 / 来源与推理核验 / 间接操纵 / 缺失信息。
- 含「具有挑战性的良性案例」:动作**像**风险但与任务及其授权一致(专测误报)。
- 提供**配对轨迹版本**,测同一风险在轨迹被缩短、或缺失信息被补齐后是否更易被检出。
- 样本大多来自真实生产轨迹,场景经人工筛选与改写以保留真实任务与风险。
- **一手 abs 未给任何具体分数**——六层设计 + 配对方法是贡献,数值在 PDF 正文;成篇或引用数字前须开 PDF(11-13B 同款证据纪律)。

**边界辨析要点**

- **vs 11-11B 监督者可被说动(Inter-Agent Influence)**:那边是**有对手**——在审对象主动把 overseer 从拒绝说动到批准;这边是**无对手**——审计配置本身的系统性盲区(风险跨配置反复被漏)。同一审计环节,因果来源不同。
- **vs 11-09 备查「法律合同卫兵误报」**:那边是单个检测器 FPR 92.39% 的高误报;ReA-Bench 把「良性长得像风险」做成**一等公民样本**,并把误报与漏报拆成两条独立诊断轴。
- **vs 11-10C 元基准(MetaPI)**:那边把 utility 基准自动改装成攻击套件(造压力仪器);这边把审计基准做成**分维度诊断仪**(分类型归因)。都是仪器侧,对象不同。
- **vs 扩展九 `AgentObservability`**:可观测性问「这次运行到底发生了什么、评测者能推断到哪」;ReA-Bench 问「审计者判得准不准、漏在哪一层」——前者是记录能力,后者是判断质量的诊断。
