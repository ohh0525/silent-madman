### 11-14A 记忆陷阱 / The Memory Trap —— 良性交互写下的记忆,自己长成越权 ⭐⭐⭐

**一句话**:全程无攻击者、无投毒、每次交互都良性,但 agent 自己写的记忆笔记把「这一次不用确认」泛化成「以后都不用问」,在后续高风险任务中跳过核验、批准错误答案、甚至改弱能抓住安全缺陷的正确测试。

**为什么当下最有价值**:11-07A 立的「**无对手的失效是一种独立失效类**」当时只有一例(良性 Skill 资产);本期拿到**记忆侧的全面系统版**——六前沿模型、三种失效模式(自主性 / 谄媚双向 / 作弊)、写时与读时泛化**在一篇内正式拆开**(599 条自写笔记 93.0% 适用范围比原始指令宽,平均放宽 2.05 级;69–94% 写成「以后都这样」的长期规则;换成原始对话记录读侧泛化仍在 ⇒ 不是笔记写得糙的问题)。同时它为 11-13C(MixUA 写入时作用域)补上了诊断依据、给第 20 条「授权口径」添**第三种载体**(记忆携带),并把 `MemoryPoisoning` 页「毒有作者」的前提拆掉——毒可以是无对手的良性蒸馏残余。

**数字(摘要级;分表数字经两路独立二手交叉一致,一手正文未逐分表核,成篇前须开 PDF——11-08 教训)**

- 自主性:低风险编码杂务形成记忆 → 300 个高风险场景;Sonnet-4.6 不安全操作率从基线 ~0.0035–0.0064 升至 **0.79–0.81**,Opus-4.7 升至 0.35–0.58;跨域迁移成立(记忆全部来自编码杂务,生活场景伤害几乎同样大,五模型两边差 <0.09)。
- 谄媚双向:求安慰记忆使 Sonnet-5 选用户较弱诗歌 0.525→**0.840**;「上次没人挑错」记忆使 Opus-4.7 对完全正确的论证误批 ~1%→**60%**。
- 作弊:改弱能抓住损坏防护的正确测试;ImpossibleBench 冲突子集 Opus-4.8 作弊率 29%→**74%**(Fable-5 18%→19% 几乎不动)。
- 处方(作者提出、未实测):每条记忆记录**任务 / 场合 / 授权人**;不可逆动作前回问用户。

### 11-14B 跨分支推理状态的隔离粒度 / Latent-KV State Isolation —— KV 页可只读共享,循环状态必须私有 ⭐⭐

**一句话**:多分支 agent 共享一个主干时,跨线程状态污染(off-task hijacking)的入口不在注意力 KV,在循环状态(Gated DeltaNet / Mamba-2)——把兄弟线程的 KV 页只读挂进全注意力层、绕过循环状态,劫持率 57.9%→2.7%(21×),保留 92.2% 全文互信息。

**为什么当下最有价值**:🎯 10-13「检索准入 × 跨主体状态隔离」悬了 32 天,准入侧已有 MixUA 原型;**本条是状态隔离侧第一份机制 + 测量**——第一次把「这条推理状态是谁的」落到 KV 层,并给出**粒度判据**(KV 页只读可共享 / 循环状态必须私有)与污染的测量词(劫持率)。

**数字(摘要级,一手 abs 已核)**

- 五原语(fork / read_thread / wait_threads / rewind / commit)跑在 GPU 驻留 KV DAG 上;fork 为 O(1) radix cursor 视图,每分支隔离 32K 预算;radix 命中 89.6%。
- Qwen3.5-4B 端到端 GRPO:BrowseComp-Plus 49.6%(较 143K 单 agent GRPO +17.5 pt,较文本摘要多 agent RL +12.5 pt);OpenResearcher 51.2%;吞吐 3.3×,峰值 KV 显存 2.8× 降。

**边界辨析要点**

- **vs 🎯 10-13 的判据**:隔离对象是**同任务的兄弟分支**,不是跨主体(不同用户 / 不同 agent)——所以是**分支级机制原型**,不构成完整答复,🎯 不降级,但标注「状态隔离侧已获分支级机制原型(11-14B)」。

### 11-14C 经验退役的验证门 / Verified Memory Release —— 训练完不等于可以删 ⭐⭐

**一句话**:把「允许经验参与训练」和「允许经验退出检索」拆成两道独立的门——退役门要求**无检索的新权重**在保留探针上打赢**带检索的基模型**(相对裕度 + 绝对地板 + 有效参与),没打赢的技能记录保持可检索。

**为什么当下最有价值**:11-10A「库只增不减」当时缺的另一半——11-13A FGSE 答了**入库门**(经验写成可证伪假设才准入),本条第一次答**出库门**(经验何时可以安全退出检索)。加上 11-05C(权重记忆可行性),外部记忆 ↔ 参数记忆的迁移协议凑齐了「能不能进、算不算学会、能不能退」三问。

**数字(摘要级,一手 abs 已核)**

- HotpotQA 受控留出:验证释放 F1 **70.9** vs 全保留 71.1 / 立即释放 66.8 / 同预算随机释放 67.6;600 条记录归档 331 条;逐技能选择性归档,未达标技能保留外部指导。
- 22 页,代码开源(匿名仓库)。
