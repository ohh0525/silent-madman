## 第二部分 · 概念雷达（3 条，落在「注入轴」的三个时位）

本期三条同属**间接提示注入的对抗面**，但各占一个**时位**、互不重叠：

- **11-04C · 事后恢复** —— 拦下**之后**，任务怎么办（承接层）

### 11-04A 详情

- **一句话定义**：埋在网页内容里、以 LLM web agent 为目标的指令文本，在整个 web 生态中的真实分布、传播方式与角色。
- **边界辨析**：与 `MemoryPoisoning` 的分界在 **persistence 步骤**（页面注入是 transient，用完即弃，不落库）；与 `ToolHallucination` 的分界在**输入侧 vs 输出侧**（污染输入 vs 捏造输出）。
- **来源**（WebSearch 真实返回，[verified]）：
  1. 论文 PDF：https://trouge.net/papers/promptinjection_ccs2026.pdf [verified]
  2. DOI：https://doi.org/10.1145/3830454.3846661 [verified]（CCS '26，The Hague）
- **值得注意的反常识点**：注入是**多利益方现象** —— 除攻击外，还被用于**数据保护与 AI bot 检测**（网站自卫）；少数**复用模板**贡献了多数实例 ⇒ 生态里存在现成的「注入工具箱」。
- **建议下一步**：这是 overview 开放项「transient indirect prompt injection 专页」的**直接素材**；值得生成 `learning-materials/prompt-injection-in-the-wild.html`（受人工核查承诺约束，先经核查）或先在 `MemoryPoisoning` 内加「野外实测」对照节。

### 11-04B 详情

- **一句话定义**：运行时审计器，为每个**状态变更动作**建立「参数 → 来源 span」的因果溯源图（IPG），仅当良性证据完整蕴含该动作、且任务不变量成立时放行。
- **边界辨析**：vs `Provenance` = **事实溯源 vs 动作溯源**（同一仪器的两个对象层）；vs 闸门 / `HumanInTheLoop` = **系统性事前证据审计 vs 流程性人审**（闸门问「要不要现在做」，ARGUS 问「这一步的证据链闭不闭合」）；vs `CitationLock` = **说的要有据 vs 做的要有据**。
- **来源**（[verified]）：
  1. https://arxiv.org/html/2605.03378 [verified]
  2. https://arxiv.org/html/2605.03378v1 [verified]（含 AgentLure 构造细节与白盒自适应攻击评估）
- **方法上的硬点**：8 个攻击向量对应 agent 从读 prompt 到发出动作之间的**8 个决策点**——攻击面按决策链而非按表面位置组织；白盒自适应攻击下 ASR 仅 5.9%（比无防御基线仍低 79%）。
- **建议下一步**：在 `Provenance` 页加「从事实溯源到动作溯源」一节，或立新概念页（仪器形态与既有 8 个概念都不重复）。

### 11-04C 详情

- **一句话定义**：检出注入后**不终止任务**，把不安全的中间响应改写为安全且可执行的替代方案，同时保持原用户意图的恢复框架。
- **边界辨析**：vs 11-04B = **事前阻断 vs 事后修复**（一个管放行、一个管续跑，互补不互替）；vs 10-31A = **量了代价 vs 给了工具**（SentryBench 证明过度拒绝是失效模式，RecoverAgent 是对该失效模式的直接回应）。
- **来源**（[verified]）：
  1. https://aclanthology.org/2026.findings-emnlp.830 [verified]
  2. https://aclanthology.org/2026.findings-emnlp.830.pdf [verified]
- **建议下一步**：作 `HumanInTheLoop` 页内「拦下之后」一节，同时给台账 10-31A 行补工具侧答案（是否并入留待拍板）。
