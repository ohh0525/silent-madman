# HTML 复用规范（concept-group-guide）

单份学习材料是 HTML，**必须复用 `learning-materials/` 既有材料的骨架与样式**，只做最小改动。一组材料的价值之一就是视觉一致 —— 不要另起一套设计。

## 1. 结构复用

复制任一份现有材料（推荐以 `learning-materials/agent.html` 为母版），保留：

- 完整的 `<!DOCTYPE html>` / `<head>` / `<style>` 块（含全部 CSS 规则）
- 版式容器：`<div class="wrap">`、`<header class="cover">`、若干 `<section>`
- 组件类：`.tag`（顶部标签）、`.def`（一句话定义盒）、`.subtitle`、表格与代码块样式
- 7 个 `<section>`，与 7 段结构一一对应

## 2. 只改这三处

| 位置 | 改什么 |
|---|---|
| `<title>` | `概念学习：<概念名>（<英文名>）` |
| `header.cover` 内文案 | `.tag` 写组名；`h1` 写概念名；`.subtitle` 写一句话定位 |
| `:root` 的两个主题色变量 | `--accent` 与 `--accent-soft` —— **只改这两个**，其余变量（`--bg` / `--panel` / `--ink` / `--ink-soft` / `--line` / `--code-bg`）保持不变 |

## 3. 主题色分配

现有已用配色（**同一组内不要复用**，避免读者混淆）：

| 概念 | `--accent` | `--accent-soft` |
|---|---|---|
| Agent（智能体） | `#b35900` 橙 | `#fff4e0` |
| 大模型上下文 | `#1a6fb4` 蓝 | `#e7f1fa` |
| Skill（技能） | `#5b3a8a` 紫 | `#efeaf6` |
| 上下文工程 | `#0e7a6d` 青 | `#e2f4f1` |
| 带溯源长期记忆 | `#b3426b` 玫红 | `#fbe9f0` |

**新组配色规则：**

1. 先取一个**本组主色调**（供组索引页使用），再为组内每个概念分配一个**同色系但可区分**的变体；如果同色系难以区分，允许跨色系但要保证任意两份不撞色。
2. 生成前先扫描 `learning-materials/*.html` 里已用的 `--accent`，**新概念不与已有概念撞色**。
3. `--accent-soft` 取同色系的极浅底色（明度接近 `#fff4e0` 这一档）。

## 4. 交叉链接

- 组内互引：用**相对路径**，如 `../learning-materials/agent.html`，或同目录直接 `<文件名>.html`
- 每份材料的第 5 段（边界辨析）里对邻居的引用，**必须指向真实存在的文件**
- 生成后实测：逐个链接检查目标文件是否存在（不要只写不验）

## 5. 组索引页

`concept-group/<group-slug>/index.html` 沿用同一套 CSS，额外需要：

- 学习路径图：用 Mermaid（`<div class="mermaid">` + CDN 或内联渲染），展示先修关系
- 概念卡片列表：每张卡 = 标题 + 一句话定义 + 相对链接
- 主色调统一用本组主色

## 6. 禁止

- 不引入新的 CSS 框架、字体、构建步骤
- 不使用外链图片或需要联网才能显示的装饰
- 不为了好看而改动既有版式（会破坏全库一致性）
