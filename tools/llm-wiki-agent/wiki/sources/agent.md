Defines AI Agent as a software system driven by an LLM that autonomously decides which tools to call around a target, observes results, and loops until the task completes or control is yielded.

## Key Claims
- Agent is not a new algorithm but an *organization* of (reasoning model + tool calls + memory + loop).
- The core mechanism is a four-step loop: receive goal + context → reason next action → execute tool + collect observation → update state + judge whether to stop.
- Common misconception: "attaching a tool makes an Agent" — Anthropic and OpenAI both require the model to *dynamically* control the execution flow.
- Practical scoping: use Agents only when steps cannot be enumerated in advance; use scripts otherwise.

## Key Quotes
> "Agent 不是某种新算法,而是把『会推理的模型 + 可以调用的工具 + 一个会停下来的循环』组织在一起,让系统能围绕目标自己挑路径。"
