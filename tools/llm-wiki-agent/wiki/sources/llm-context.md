## Summary
A concept-learning HTML document generated by silent-madman's concept-explainer skill on 2026-09-05. Defines the LLM context window as the maximum number of tokens the model can simultaneously read and reference in a single inference pass. The mechanism covers BPE tokenization, positional encoding + self-attention, total length judgment + truncation, and attention-weight shifting (Lost in the Middle).

## Key Claims
- Context window is the model's "short-term memory desktop" — sized in tokens, not characters (Chinese characters average 1.5–2 tokens each).
- Self-attention cost grows as n²; 1000 tokens → 1M pair-wise relations, 10000 tokens → 100M.
- Most commercial APIs *silently truncate* on overflow rather than raising an error — explaining the common "AI amnesia" experience.
- "Lost in the Middle": even within window, the model attends strongest to system prompt + current question; middle content gets weaker attention.

## Key Quotes
