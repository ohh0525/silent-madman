## Summary
A concept-learning HTML document (7-section format) generated by the silent-madman concept-explainer skill on 2026-09-16. Defines provenance-aware long-term memory as the design discipline in which every stored fact carries its origin, timestamp, and evidence pointer, and every answer is produced under a *citation lock* — it may cite only evidence the reader actually opened. Fabrication is structurally excluded and the system abstains rather than guesses. Anchored by the Agent Zero Memory paper (arXiv:2608.29606) and the LongMemEval benchmark.

## Key Claims
- A single general-purpose memory store (vector index or knowledge graph) inherits that structure's blind spots; better to run **three parallel purpose-built memories**: episodic (event timeline), associative (entity–event graph), and semantic (citation-locked Hierarchical Documentary Memory, HDM).
- Retrieval runs an **intent gate** (self-contained turns add no latency) → **source router** → **three concurrent agentic searches** (hybrid embedding + lexical, agent-controlled filters), integrated into one answer with a single confidence.
- **Reading discipline:** every learned item is a provenanced item (origin + timestamp + evidence pointer); every answer is read under a citation lock, so it may cite only evidence actually opened → fabrication is structurally impossible, and the system abstains instead of guessing.
- Memory errors **compound**: a one-turn hallucination is transient, but a mistake *written* to durable memory becomes a recurring input to every future plan. Prompt-injection poisoning persists across all future sessions ("one write, permanent compromise").
- Memory writes are **side effects with blast radius** — they should get the same engineering discipline as any external action (source grading, TTL, validation on write, filtering on read, and a real, loggable "forget").
- Quantitative: Agent Zero Memory scores **95.60%** on LongMemEval and **93.60%** on LoCoMo (best prior +0.73 / +1.10); across 8 LLM backbones accuracy varies only **3.4 points** while per-query cost varies **~30×** — the signature of *memory-driven, not model-driven, quality*.
- LongMemEval shows naive long-context reading of full 115K-token histories drops **30%–60%** accuracy vs. evidence-only; commercial assistants reach only **30%–70%**.

## Key Quotes
> "带溯源的长期记忆不是『记得更多』，而是『记得更诚实』——每条事实都带着来源与时间，每次作答都必须引用真正打开过的证据；当没有依据时，正确的输出是『我不知道』。"
> "虚拟内存若没有溯源，只是让坏状态优雅地规模化。"
