## Summary
A concept-learning HTML document generated by silent-madman's concept-explainer skill on 2026-09-05. Defines Skill as an organized folder of instructions, scripts, and resources that Claude loads on demand when a task is relevant — turning a general model into a domain expert. The core mechanism is *progressive disclosure* (YAML metadata → SKILL.md body → referenced scripts/assets), which fits unlimited expertise into a bounded context window.

## Key Claims
- Skill is not a prompt template — it is a cross-conversation, version-controlled, multi-product-shared directory.
- Three-layer progressive disclosure: (1) YAML metadata always in system prompt, (2) SKILL.md body loaded when relevant, (3) scripts/assets loaded on demand.
- Same Skill folder works across Claude app, Claude Code, API, Agent SDK; released as an open standard after 2025-12.
- Skill is *not* MCP: Skill teaches the model how to use tools; MCP standardizes the tool connection itself.

## Key Quotes
> "Skill 不是『让模型变聪明』,而是『把组织经验打包成可按需加载的目录』,用渐进式披露在有限的上下文里装下无限的专业知识。"
