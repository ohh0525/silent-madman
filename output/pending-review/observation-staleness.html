1 · 一句话定义，以及缝在哪

一条观察不会因为它被写下来时为真，就在被取用的那一刻仍然为真。「观察的时效性」问的不是「这条记录从哪来」，而是「这个来源现在还支不支持这句话」 —— 它是记忆簇的读侧 / 现在时半张图。

这个知识库里已有的页，各自守着一段不同的因果：

已有页它管什么它不管什么
[[Provenance]]入口：写进来时有没有来源来源后来变没变
[[MemoryGovernance]]生命周期：谁有权增删改查内容是否仍为真
[[ContextRot]]量：token 一多就糊内容效度（量不大也会失效）
[[CitationLock]] / [[Abstention]]引用要打开过 / 没证据要拒答打开过也可能已经过期；有证据但过期也要拒用

⇒ 四者合起来仍留着一格：一条携带合法来源、篇幅适中、被正确引用、也有权留在记忆里的内容，完全可能是过期的。这类失效没有攻击者 —— 与 [[MemoryPoisoning]] 的「有人写了假的」正好互补：那边是内容被污染，这边是内容没被污染，是世界变了。这也是本库「无对手失效」家族的第二个成员（第一个是 11-07A 的良性 Skill）。

3 · 四种「还真的吗」失效形态

  1. 源变了（source drift）：读过 config.yaml，用户随后改了它，模型仍按旧内容回答。来源合法、内容曾经为真，错的是时间。Concord 的直接对象。
  2. 证据失效（evidence invalidation）：长程编码任务里，上一阶段的测试输出在仓库被跨文件修复后不再成立；恢复历史证据等于恢复一个已经不存在的世界。MemTrace 的直接对象。
  3. 范围脱落（scope detachment）：「如果改用方案 B 会怎样」被压成「方案 B 可行」；被模拟的工具结果被当成真的跑过。记录既不假也不无关，只是脱离了它成立时的语境。CASK 的直接对象。
  4. 隐式依赖（implicit reliance）：直接问「这条还有效吗」时模型大多能识别过期；但让它顺势用上这条事实时，识别率大幅下跌 [二手转述，未独立复现] ⇒ 失效最容易在没人问的时候发生。
判据句：失效不是内容属性，是内容 × 取用时刻的属性。 所以「存的时候验一次」不够。

4 · 与已覆盖概念的边界辨析

对比一句话划界
vs [[Provenance]]从哪来 vs 这个来源现在还支不支持这句话。来源合格是过去的成就，不是此刻的许可。
vs [[CitationLock]]引用要打开过 vs 打开过也可能已经过期 —— 打开是空间动作，再验证是时间动作。
vs [[ContextRot]]精度随长度下降（量） vs 效度随世界变化下降（时间）。短上下文照样会过期。
vs [[Compaction]]说得少一点 vs 说得对不对。压缩保不住效度，甚至会把「何时成立」这层元数据压掉。
vs [[MemoryGovernance]]谁有权增删改查 vs 留下的内容是否仍为真。权限正确不蕴含内容正确。
vs [[MemoryPoisoning]]有人写了假的（有对手） vs 没人写假，是世界变了（无对手）⇒ 检测式防御在本条上同样无处落脚：没有任何异常内容可检测。
vs [[Abstention]]没证据要拒答 vs 有证据但已过期也要拒用 ⇒ [[Abstention]] 的对象第一次从「事实」扩到「事实的有效期」。
vs 09-23「持久化执行」状态能不能恢复 vs 恢复出来的证据还成不成立。checkpoint ≠ memory 的第二个版本。
vs 10-13「检索准入」语义 / 权限上能不能用在这里 vs 时间上还成不成立。两条不同的拒绝理由，需要两条不同的判据。

6 · 可抄走的工程规则

  1. 验证挂在复用侧，不是写入侧。 validate before reuse —— 存的时候为真只在存的时候有用；MemTrace 把它做成「恢复历史证据前的一道校验」，Concord 做成「复用陈旧上下文前的 update / annotate / suppress」。
  2. 观察要链接回可变来源。 只存文本不存「它从哪个文件 / 哪个 commit / 哪次工具调用来」，就没有东西可以再验证。可失效性是一种需要被存下来的元数据。
  3. 缓存要有第四个动词。 除了 read / write / evict，还需要 invalidate on external change [二手归纳，未独立复现]；同理，目标要钉成可失效的，而不是不可变的。
  4. 记录时保留范围。 把「谁在这个分支里说的、哪个世界许可它」一起写进记录；CASK 的结论是保留稳定关系而非内部坐标，因为等价表示未必共享坐标。
  5. 别只测「问它知不知道过期」。 直接询问与隐式依赖的表现差距很大 [二手数字] ⇒ 评测必须把过期内容放进没人提醒的正常使用路径里。

9 · 一句话回顾

写下来时是真的，不等于取用时还真的。 来源管的是过去，权限管的是人，量管的是篇幅 —— 没有一页管「世界在它背后动了」。修法不在存的那一步，而在复用之前再问一次：这条观察，现在还成立吗？
