使用说明

本练习册配套《Python 基础语法讲义（第 1–4 课）》使用，每课包含三部分：概念自测（检验理解）、上机编程题（检验动手能力）、综合应用题（检验整合能力）。

使用建议：

  1. 先做后看。答案集中在文档后半部分，请务必先独立完成，再对照答案。直接看答案的学习效果接近于零。
  2. 答案不是唯一解。参考答案给出的是一种规范写法，如果你的代码能跑出相同结果，逻辑也清晰，那就是好代码。
  3. 务必实际运行。编程题必须敲进 Notebook 运行一遍，看到输出才算完成。看懂了和写出来是两件不同的事。
  4. 记录报错。做题过程中遇到报错，把报错信息抄下来，对照讲义第 3 课的异常类型速查表判断原因，这个习惯比做对题本身更有价值。

题量说明：每课概念题 5 题、编程题 5～6 题、综合题 1 题，预计用时 60～90 分钟。

2-5

答：列表用位置（下标）定位数据，形如 [88, 92, 75]，天然对应表格中的"一列"。字典用键名定位数据，形如 {"name": "张三", "score": 92}，天然对应表格中的"一行记录"——每个字段名映射到一个值。

第 4 课的 DataFrame 正是这两者的结合：它有列名（像字典的键）也有行索引（像列表的下标），因此既能按列取值（df["score"]，相当于取一个列表），也能按行取记录。理解了列表与字典，DataFrame 就只是把两者拼在一起。

def median(scores):
    if len(scores) == 0:
        return None

    data = sorted(scores)
    n = len(data)
    mid = n // 2

    if n % 2 == 1:
        return data[mid]
    else:
        return (data[mid - 1] + data[mid]) / 2

print(median([88, 92, 75]))
print(median([60, 70, 80, 90]))

预期输出：

88
75.0

解析：中位数必须先排序。奇数个元素取正中间；偶数个元素取中间两个的平均值。

def average(scores):

        return None

def variance(scores):
    avg = average(scores)
    total = 0
    for s in scores:
        total = total + (s - avg) ** 2
    return total / len(scores)

print(variance([88, 92, 75, 60, 95]))

165.04

解析：函数之间可以互相调用，这正是封装的价值——方差的定义依赖均值，直接复用 average() 即可，无需重复实现。

def load_scores(path):
    names, scores = [], []
    with open(path, "r", encoding="utf-8") as f:
        lines = f.readlines()

    for line in lines[1:]:
        line = line.strip()
        if line == "":
            continue
        parts = line.split(",")
        names.append(parts[0])
        scores.append(float(parts[1]))

    return names, scores

import numpy as np
import pandas as pd

df = pd.DataFrame({
    "name": ["张三", "李四", "王五", "赵六"],
    "score": [92, np.nan, 88, np.nan],
})

print(f"原始行数 {len(df)}，均值 {df['score'].mean():.2f}")

dropped = df.dropna(subset=["score"])
print(f"删除缺失行后 {len(dropped)} 行，均值 {dropped['score'].mean():.2f}")

filled = df.copy()
filled["score"] = filled["score"].fillna(filled["score"].mean())
print(f"均值填充后 {len(filled)} 行，均值 {filled['score'].mean():.2f}，标准差 {filled['score'].std():.2f}")

解析：注意 df["score"].mean() 会自动跳过 NaN，因此填充用的均值是 90.00。填充后行数不变，但标准差明显小于删除缺失行后的结果——这正是"填充会压缩离散程度"的直接证据。df.copy() 用于避免直接修改原数据。
