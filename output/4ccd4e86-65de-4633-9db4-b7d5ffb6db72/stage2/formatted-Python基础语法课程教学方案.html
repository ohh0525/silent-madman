一、课程概述

本课程的定位、学习目标与适用对象如下。

1.1 课程定位

本课程是一门面向零基础学习者的 Python 入门课程，共 4 次课、8 个课时（每次课分上、下两个 45 分钟场次，合计 6 小时）。课程以"能动手做统计分析"为最终落脚点，语法讲解始终围绕数据处理场景展开——每一个知识点都对应后续统计分析中的一项具体能力，避免出现"语法学会了但不知道怎么用"的脱节。

课程不追求语法大全式的覆盖，而是遵循"最小完备"原则：只讲数据分析真正高频使用的语法子集，把节省下来的时间投入到动手练习上。学完本课程，学习者应当具备独立使用 Python 读取数据、清洗数据、完成描述性统计并输出分析结论的能力。

1.2 学习目标

知识目标

  1. 掌握 Python 的变量、核心数据类型、运算符与字符串处理；
  2. 掌握条件判断与循环控制，理解程序的执行流程；
  3. 掌握列表、元组、字典、集合四种内置数据结构及其适用场景；
  4. 掌握函数的定义、参数传递与返回值，理解模块与包的导入机制；
  5. 了解文件读写与异常处理的基本方法；
  6. 认识 NumPy 与 pandas 的核心对象，理解向量化运算与数据框操作。

能力目标

  1. 能独立完成 Python 与开发环境的安装配置，并在 Jupyter Notebook 中运行代码；
  2. 能读懂并修改他人编写的中等长度 Python 脚本；
  3. 能把一个自然语言描述的数据处理需求，翻译成由循环、条件与函数构成的程序；
  4. 能独立完成"读取数据 → 清洗数据 → 描述统计 → 分组对比 → 简单可视化"的完整分析流程；
  5. 能看懂并处理常见的运行错误（NameError、TypeError、KeyError、FileNotFoundError 等）。

素养目标

  1. 建立"先看懂数据、再动手分析"的工作习惯；
  2. 形成主动查阅官方文档与错误信息的学习方式；
  3. 理解数据分析结论必须由数据支撑，不凭直觉下判断。

1.3 目标学员与前置要求

项目 说明
目标学员 零编程基础的在校学生、职场人士、研究人员
前置知识 无编程要求；具备基本的计算机文件操作能力（新建文件夹、解压、复制路径）即可
数学基础 了解平均数、中位数、百分比等基本统计概念即可，不要求微积分与线性代数
硬件要求 能正常联网的电脑，建议内存 8GB 及以上
时间投入 课堂 6 小时 + 课后练习约 6～8 小时

二、课程整体设计

课程按四次课递进展开，课次划分、课时结构与教学方式安排如下。

2.1 四次课总览

课次 主题 核心内容 对应统计能力
第 1 课 环境搭建与基础语法 环境配置、变量、数据类型、字符串、运算符、输入输出 能表达和存储单个数据
第 2 课 流程控制与数据结构 条件判断、for/while 循环、列表、元组、字典、集合 能批量处理一列数据
第 3 课 函数、模块与文件 函数定义与调用、参数、lambda、模块导入、文件读写、异常处理 能封装分析逻辑、读取数据文件
第 4 课 统计分析实战 NumPy 数组、pandas 数据框、描述统计、分组聚合、小项目 能完成一份完整的数据分析

四课之间是严格的递进关系：第 1 课解决"数据怎么存"，第 2 课解决"数据怎么批量算"，第 3 课解决"逻辑怎么复用、数据怎么读进来"，第 4 课把所有能力整合成一条完整的分析流水线。因此不建议跳课学习；若确有基础需要跳课，至少应完成对应的课后练习自测。

2.2 课时结构与讲练配比

每次课 90 分钟，按"上半场 45 分钟 + 下半场 45 分钟"组织。整体讲练比控制在 6:4 左右——讲授 55 分钟，动手练习 35 分钟。每个半场的前段讲授新知识，后段立即安排对应练习，避免知识堆积到课后才动手。

场次 时长 环节 说明
上半场开始 5 分钟 回顾与导入 回顾上次要点，抛出本次课要解决的问题
上半场中段 30 分钟 新知识讲授 概念讲解 + 现场演示代码
上半场末段 10 分钟 跟随练习 学员照着敲一遍，教师巡场答疑
下半场开始 25 分钟 新知识讲授 延续上半场，难度递进
下半场中段 15 分钟 独立练习 学员独立完成，教师个别指导
下半场结束 5 分钟 小结与作业 总结要点，布置课后作业

2.3 教学方式

  1. 现场编码（Live Coding）：教师在 Jupyter Notebook 中现场敲代码，学员同步跟随。所有示例代码均现场运行、当场看结果，不做"贴代码念一遍"式讲授。
  2. 错误驱动教学：每节课刻意演示 2～3 个典型错误，让学员看见报错、读懂报错、学会排查。这比只讲正确写法更有效。
  3. 数据场景贯穿：所有示例均使用同一套数据集（如某班级学生成绩表、某门店月度销售表），四次课下来，学员对同一份数据的处理能力逐层加深。
  4. 结对互查：练习环节建议两人一组，互相读对方的代码并复述其逻辑，用以检验理解程度。

三、分次课教学安排

以下按课次说明每个半场的教学内容与教学目标，授课时可逐行对照使用。

3.1 第 1 课：环境搭建与基础语法

上半场（45 分钟）——跑起来第一行代码

时间 内容 教学目标
0～15 分钟 安装 Python 与 Anaconda，认识 Jupyter Notebook 界面 能独立启动 Notebook 并新建运行一个单元格
15～25 分钟 变量与赋值、命名规则、动态类型 理解变量是"贴了标签的数据"
25～40 分钟 int、float、str、bool 四种基本类型，type() 与类型转换 能判断一个值的类型并正确转换
40～45 分钟 跟随练习：计算一组商品价格的总额与均价 巩固变量与数值运算

下半场（45 分钟）——操作数据的第一步

时间 内容 教学目标
0～15 分钟 字符串操作：索引与切片、拼接、f-string、split/strip/replace 能对文本型字段做基本清洗
15～30 分钟 运算符：算术（重点 //、%、**）、比较、逻辑（and/or/not） 能用一行表达式完成常见计算
30～40 分钟 input() 与 print() 格式化输出、注释规范 能写出有输入有输出的完整小程序
40～45 分钟 独立练习：输入三科成绩，输出总分与平均分 综合运用类型转换与运算

重点提示：type() 与类型转换是本课的隐性重点。后续读取数据时，最常见的问题就是"明明是数字却被当成了文本"，根源都在这里。

3.2 第 2 课：流程控制与数据结构

上半场（45 分钟）——让程序会"判断"和"重复"

时间 内容 教学目标
0～15 分钟 if / elif / else，嵌套判断，缩进规则 能把分段规则写成条件语句
15～30 分钟 for 循环、range()、遍历列表，break / continue 能批量处理一列数据
30～40 分钟 while 循环与累加器模式 理解不定次数的循环
40～45 分钟 练习：循环计算 1～100 的均值、筛选及格成绩 巩固循环与累加器写法

下半场（45 分钟）——数据怎么"装"

时间 内容 教学目标
0～15 分钟 列表：增删改查、排序、len/sum/max/min 能用列表承载"一列数据"
15～25 分钟 元组与集合：不可变序列、去重与集合运算 知道三者各自的适用场景
25～40 分钟 字典：键值对、遍历、嵌套字典 理解"字段名 → 值"的映射，为 DataFrame 铺垫
40～45 分钟 独立练习：用字典统计一段文本的词频并排序输出 综合运用循环与字典

重点提示：本课是四次课中的第一个分水岭。列表与字典的理解程度直接决定第 4 课的学习体验——pandas 的 Series 本质上是"带索引的列表"，DataFrame 本质上是"共享索引的字典"。

3.3 第 3 课：函数、模块与文件

上半场（45 分钟）——封装你的统计逻辑

时间 内容 教学目标
0～20 分钟 def 定义函数、参数、返回值、默认参数、关键字参数 能把重复逻辑封装成函数
20～30 分钟 作用域：局部变量与全局变量 理解为什么函数内改变量不影响外部
30～40 分钟 lambda 匿名函数与 sorted(key=...)、map 能写出简洁的排序与映射表达式
40～45 分钟 练习：编写求均值、中位数、方差的统计函数 把统计口径固化成可复用代码

下半场（45 分钟）——让数据进得来、错误不崩溃

时间 内容 教学目标
0～15 分钟 模块与包的概念，import 的几种写法，pip 安装第三方库 能安装并导入需要的库
15～30 分钟 文件读写：open()、with 语句、read/readlines、写入模式 能读取 csv/txt 文件并解析
30～40 分钟 异常处理：try / except / finally，常见异常类型 能让程序在出错时不中断
40～45 分钟 练习：读取 csv 文件并打印前几行与总行数 打通"文件 → 数据"的链路

重点提示：lambda 与 sorted(key=...) 是第 4 课 pandas apply、sort_values 的前置知识，务必练熟。

3.4 第 4 课：统计分析实战

上半场（45 分钟）——数据分析的两大神器

时间 内容 教学目标
0～20 分钟 NumPy 数组的创建、形状与广播、向量化运算、mean/std/median 理解向量化替代循环的价值
20～40 分钟 pandas 的 Series 与 DataFrame、read_csv、head/info/describe 能读入数据并快速了解数据全貌
40～45 分钟 答疑与知识回填 澄清前三课的遗留疑问

下半场（45 分钟）——完整走一遍分析流程

时间 内容 教学目标
0～15 分钟 数据清洗：缺失值、重复值、类型转换、列选择与条件筛选 能把原始数据整理成可分析的形态
15～30 分钟 分组聚合：groupby、聚合函数、value_counts、排序 能做分组对比分析
30～45 分钟 实战小项目：读取真实数据集，完成完整分析并得出结论 独立交付一份一页纸分析报告

重点提示：groupby 是本课的核心，也是实际工作中使用频率最高的操作。建议学员把"按某字段分组、对某字段求均值、按结果排序"这条动作练到不用看笔记就能写出来。

四、教学环境与资源

本课程所需的软件环境、数据资源与代码材料如下。

4.1 软件环境

组件 推荐版本 说明
Python 3.10 及以上 版本过低的部分语法与库不兼容
发行版 Anaconda（含 Jupyter Notebook） 一次装齐常用数据分析库，避免逐个 pip 安装
编辑器 Jupyter Notebook（课堂）/ VS Code（课后） 课堂用 Notebook 便于逐步运行与展示
核心库 NumPy、pandas、Matplotlib 第 4 课依赖

安装完成后，建议用一段最小代码验证环境是否正常：

import sys
print(sys.version)

import pandas as pd
print(pd.__version__)

若两行版本号都能正常打印，说明环境就绪。

4.2 数据与案例资源

  1. 贯穿数据集：一份不少于 200 行的示例数据表（建议字段包含分类字段、数值字段、日期字段与少量缺失值），供四次课反复使用。
  2. 课后数据集：第 4 课结课项目所需的一个公开数据集，建议包含 500 行以上数据。
  3. 代码模板：每个半场结束后发放当堂完整代码，供学员对照复盘。

五、作业、考核与结课产出

作业安排、考核维度与结课产出标准如下。

5.1 课后作业安排

课次 作业内容 预计用时
第 1 课 完成基础语法练习题 10 题，输出一组成绩统计结果 60 分钟
第 2 课 用循环与字典完成一个词频统计程序 80 分钟

5.2 考核方式

本课程采用过程性考核为主、结课项目为辅的方式，不设笔试。

考核维度 权重 评分要点
课堂参与与练习完成度 20% 四个半场练习是否按要求完成
课后作业 30% 代码可运行、逻辑正确、有必要的注释
结课项目 40% 分析流程完整、结论由数据支撑、结论表述清晰
代码规范与可读性 10% 变量命名有意义、结构清晰、无冗余代码

5.3 结课产出标准

结课项目须提交一份分析报告，包含以下五个部分：

  1. 数据说明：数据来源、字段含义、数据量级；
  2. 数据清洗记录：处理了哪些缺失值、异常值与重复值，依据是什么；
  3. 描述统计：关键字段的均值、中位数、标准差、分布特征；
  4. 分组对比：至少按一个维度分组，比较组间差异；
  5. 结论与局限：给出 3 条由数据支撑的结论，并说明本次分析的局限性。

注：结论部分不允许出现没有数据支撑的主观判断。每一条结论都必须能指出对应的统计结果。

六、教学建议与常见问题

以下分别给出给教师的实施建议，以及学员常见问题的应对办法。

6.1 给教师的建议

  1. 不要替学员敲代码。练习时学员卡住，优先引导其读懂报错信息，而不是直接给出正确写法。
  2. 控制示例复杂度。每个知识点的示例代码控制在 10 行以内，超过就拆分。
  3. 反复回到同一份数据。让学员在熟悉的语境中体会能力的增长，比不断更换案例更有效。
  4. 第 2 课和第 4 课适当放慢。这两课是难点，可视学员掌握情况压缩其他环节，保证核心内容的练习时间。

6.2 常见问题

问题 应对建议
环境安装失败 优先改用 Anaconda 图形化安装；课堂预留 10 分钟统一排障
看不懂英文报错 教一套固定读法：先看最后一行错误类型，再看报错行号，最后看中间的调用链
语法能看懂但写不出 属于正常现象，解决办法是"抄—改—默写"三步：先照抄示例，再改参数，最后合上笔记重写一遍
学到第 4 课感觉跟不上 大概率是第 2 课的数据结构没练熟，建议回做第 2 课练习后再继续
课后没有数据可练 使用课程提供的示例数据集，或从公开数据平台下载 csv 文件

附录 B 结课能力验收清单

学完全部四次课后，请逐项自检。全部能独立完成，即达到本课程的能力目标。

  1. 能在自己电脑上安装 Python 环境并新建一个 Notebook 文件；
  2. 能解释 int、float、str、bool 四种类型的区别，并完成相互转换；
