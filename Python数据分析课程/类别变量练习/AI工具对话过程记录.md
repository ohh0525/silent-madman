## 阶段 3 · 关键决策：独立复算（不照抄）

**AI 判断**：用户有一贯要求——「引用必须真实、声明必须实测验证，助手说完完成后用户会追问确认」。子代理的统计数字**必须经过独立复算**才能写进报告。

**环境限制**：沙盒 Python 3.13 无 numpy / pandas / scipy。

**AI 动作**：编写 `recheck_stats.py`，用纯标准库实现：
- 卡方分布生存函数 → 正则化上不完全 gamma 函数（Numerical Recipes 的级数法 + 连分数法）
- Cramér's V = √(χ² / (n·min(r−1,c−1)))
- Yates 校正卡方
- 2×2 Fisher 精确检验（超几何分布枚举所有表格，双尾累加）

**复算对照结果（逐项吻合）**：

| 指标 | 子代理 | 独立复算 | 一致 |
|---|---|---|---|
| 6×6 χ² / p / V | 42.01 / 0.017 / 0.406 | 42.0049 / 0.017951 / 0.4059 | ✅ |
| 2×3 χ² / p / V | 19.71 / 5.2e-5 / 0.622 | 19.7101 / 5.248e-5 / 0.6217 | ✅ |
| 2×2 χ² / p / V | 8.77 / 0.0031 / 0.474 | 8.7698 / 0.003063 / 0.4742 | ✅ |
| 2×2 Yates χ² / p | 6.91 / 0.0086 | 6.9143 / 0.008551 | ✅ |
| 2×2 Fisher p | ≈0.0069 | 0.006916 | ✅ |
| 六分类完全一致 | 21/51 = 41.2% | 21/51 = 41.2% | ✅ |

同时独立核对了清理统计（53 条、1 空、1 个「无」、2 条重复），全部吻合。

**决策点 ②**：6×6 细粒度表因期望频数严重不足（35/36 格 < 5，20 格 < 1），其 p 值**仅供描述、不可推断**；正式推断采用合并后的 2×3 与 2×2 口径。这是本次分析最重要的 methodological 判断。

## 附：方法论要点沉淀

1. **先定位再动手**：文件找不到时先问位置，不用编造数据填坑。
2. **编码问题是定位问题**：GBK 文件做纯字节转码，不改数据语义；跨行字段必须按 CSV 引号规则解析。
3. **统计前提优先于统计结果**：期望频数不足时，p 值再漂亮也不可推断；合并类别是必需步骤而非可选项。
4. **不照抄、要复算**：关键数字用独立实现交叉验证后才写入交付物。
5. **引用要真**：多学科解读的每一条理论都对应真实检索来源，附 URL。
6. **长文件写后必校验**：闭合标记 + 字节数 + 尾部内容。
7. **独立脚本的哨兵只能出现一次**：模板注入时用 `str.replace(marker, html, 1)` 或改用内容特征判断，避免全局替换误伤。
